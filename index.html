1. Chords go in square brackets

Put the chord right before the word (or the sound) it belongs on.

[G]Amazing [C]grace, how [G]sweet the [D]sound
Hal[C]le[G]lujah

2. Name each part by typing its name on its own line

Type one of these words alone on a line. The app makes it a heading. No start or end code needed.

Verse 1:
Chorus:
Bridge:
Pre-Chorus:
Intro:    Outro:    Tag:    Interlude:

A part runs until the next heading. Leave a blank line for a gap.

Another language? (Spanish, Portuguese, French, Chinese…)

These words are recognized for you: Coro, Estribillo, Verso, Estrofa, Puente, Pre-Coro, Final, Interludio, Refrão, Couplet, Pont, 主歌, 副歌, 橋段.

Any other word works too. Put it on its own line, after a blank line, and end it with a colon:

Coro:
Verso 2:
Estribillo final:

The sure-fire way, in any language, is a code with your own word after the colon:

{soc: Coro}   ...   {eoc}
{sov: Verso 1}   ...   {eov}
{sob: Puente}   ...   {eob}

(soc = start of chorus, sov = start of verse, sob = start of bridge. The e ones end them. Ending is optional.)

3. Song details go in curly braces at the top

{title: Amazing Grace}
{artist: John Newton}
{key: G}
{capo: 2}

4. A note for the band

{comment: Play softly}
{comment: Repeat x2}

5. A note just for you (hidden)

# this line does not show on the sheet

The long way (you can skip this)

Start and end codes also work. They are the same as typing the heading.

{start_of_verse: Verse 1}  ...  {end_of_verse}
{start_of_chorus}  ...  {end_of_chorus}
{start_of_bridge: Bridge}  ...  {end_of_bridge}
short forms:  {sov} {eov}   {soc} {eoc}   {sob} {eob}

Number charts (1 4 5 6m)

Type the numbers in brackets, like [1] [4] [6m], and add {key: G}. Use the "Chords as written" menu to show letters or numbers.

Buttons in plain words

  • [ ] chord: puts a pair of brackets where your cursor is. If you highlight a word first, it wraps the word.
  • Convert pasted chords-over-lyrics: paste a chart where chords sit above the words, then tap this.
  • ♭ − / + ♯: change the key. A− / A+: smaller / bigger text.
  • Export ▾: everything you can save, in one menu: PDF, picture (JPG or PNG), the .cho file, .cho + PDF together, Print, or Share. PDFs use a bold, clean font and shrink to fit on one page (two at most), so they read well in a dark room. A verse, chorus or bridge is never split across pages or columns. In Chrome or Edge, saving opens a normal Save window that starts in the folder the song came from, so you can drop the PDF right next to it. In Safari, pages cannot choose a folder: set Safari, Settings, General, File download location to Ask for each download. On an iPhone they open the Share sheet, where Save to Files puts the file anywhere you like.
  • Import: opens .cho, .txt, .docx, .rtf or .pdf files.
  • Open library folder: search a whole folder of songs without importing them.
